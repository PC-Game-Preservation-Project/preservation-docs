# Preservation Project Documentation

This repository contains documentation for the preservation project, including guides, FAQs, and reference material related to archived software, disc images, copy protection, and other preservation topics.

## Documentation

- [CD/DVD Disc Images & Copy Protection FAQ](cd-dvd-copy-protection-faq.md)  
  Explains the disc image formats used in the CD/DVD collections, copy-protection types, the **CP** column, virtual drive compatibility, and modern compatibility tools for older protected software.

## About This Repository

The documentation in this repository is intended to accompany preserved software collections hosted on [Archive.org](https://archive.org/).

Additional guides and reference material will be added as the project grows.
